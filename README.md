# Шедулер повторений 1-3-7-21-30 для RemNote

Плагин для RemNote, реализующий строгий интервальный график повторения и умное обновление описаний карточек через ИИ.

## Возможности

1. **Фиксированный шедулер повторений (`Fixed 1-3-7-21-30`)**:
   - Карточки повторяются строго по фиксированной сетке интервалов:
     - 1-е повторение: **+1 день**
     - 2-е повторение: **+3 дня**
     - 3-е повторение: **+7 дней**
     - 4-е повторение: **+21 день**
     - 5-е повторение: **+30 дней**
     - Последующие повторения: **60, 90, 180, 360 дней** (с удвоением интервалов).
   - Шедулер можно назначить как глобально на всю базу, так и точечно на конкретную папку или документ через `Flashcard Settings`.

2. **Обновление описаний и формулировок карточек (Claude API)**:
   - Команда в палитре: `Обновить описания карточек в этой папке (Claude)`.
   - Автоматически обходит все карточки в выбранной папке и переформулирует пары «вопрос-ответ», делая их технически точными, лаконичными и понятными.

## Установка и использование

### Вариант 1. Через Developer Plugins (локально)
1. Склонируйте репозиторий и установите зависимости:
   ```bash
   npm install
   npm run dev
   ```
2. В RemNote откройте **Настройки** (`Ctrl+,`) → **Plugins** → **Developer Plugins**.
3. Укажите адрес: `http://localhost:8080` и нажмите **Разрабатывать**.

### Вариант 2. Установка из архива
1. Соберите архив плагина:
   ```bash
   npm run build
   ```
2. В RemNote перейдите в **Settings** → **Plugins** → **Install from Zip** и выберите `PluginZip.zip`.

## Настройка шедулера на папку
1. Откройте нужную папку в RemNote.
2. Нажмите меню `···` (вверху справа) → **Flashcard Settings**.
3. В поле **Scheduler** выберите `Fixed 1-3-7-21-30`.
