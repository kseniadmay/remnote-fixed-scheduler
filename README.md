# Планировщик повторений 1-3-7-21-30 (RemNote Fixed Scheduler)

Плагин интервального повторения для RemNote с фиксированной прогрессией шагов: **1 → 3 → 7 → 21 → 30 дней** (и долгосрочный цикл 60, 90, 180, 360 дней).  
Разработан для планомерного изучения конспектов и учебных материалов без перегрузки очереди флеш-карточек неизученными темами.

---

## Возможности

### 1. Предсказуемая сетка интервалов (Fixed Spaced Repetition)
В отличие от стандартного адаптивного алгоритма, плагин использует фиксированные интервалы повторений:
- **Старт**: первое повторение через **1 день** (завтра) после фактического прочтения и активации конспекта.
- **1-е повторение**: через **3 дня**.
- **2-е повторение**: через **7 дней**.
- **3-е повторение**: через **21 день**.
- **4-е повторение**: через **30 дней**.
- **Долгосрочный цикл**: 60 → 90 → 180 → 360 дней (с последующим удвоением интервала).

В настройках колод и документов алгоритм регистрируется под именами:
- `Планировщик повторений 1-3-7-21-30` (основное)
- `Расписание повторений 1-3-7-21-30` (синоним)
- `Fixed 1-3-7-21-30`

---

### 2. Контроль очереди изучения: пауза и активация карточек

Чтобы карточки будущих тем и модулей не засоряли очередь практики раньше времени, плагин поддерживает управляемый жизненный цикл конспекта:

* **Постановка на паузу (Pause)**:
  - Добавляет на документ системный powerup `BuiltInPowerupCodes.DisableCards`.
  - Карточки документа и всех дочерних элементов временно исключаются из ежедневной очереди практики, сохраняя весь прогресс.
* **Активация конспекта (Activate)**:
  - Снимает powerup `DisableCards` с документа и прямых дочерних карточек.
  - Назначает первое повторение карточек на следующий день (+1 день от момента активации).

---

### 3. Интерактивная панель документа (`NoteSchedulerBar`)
Прямо под заголовком открытого конспекта встраивается удобная панель управления:
- Отображает текущий статус конспекта (на паузе или активен).
- Кнопка **«📖 Изучено — запустить повторение»** для мгновенной активации.
- Кнопка **«⏸️ Приостановить»** для временного исключения конспекта из очереди.

---

### 4. Вспомогательные команды для организации конспектов

- **`🔢 Выровнять нумерацию конспектов (01, 02, 03...)`**:  
  Проходит по всем темам в выбранной папке или модуле и приводит их номера к аккуратному двухзначному формату (`01. ...`, `02. ...`). Устраняет скачки нумерации и нахлёсты. Не меняет системный тип элементов, поэтому они не пропадают из боковой панели (сайдбара).
- **`🔗 Сделать все ссылки программы рабочими (привязать к конспектам)`**:  
  Связывает элементы учебной программы прямыми ссылками RemNote с существующими файлами конспектов и вычищает битые ссылки `about:blank`.

## Команды и вызов в интерфейсе

### Через командную строку (`Ctrl + K` / `Ctrl + P`)
1. `Конспект прочитан — поставить на повторение (1-3-7-21-30)`
2. `Приостановить повторение конспекта`
3. `🔢 Выровнять нумерацию конспектов (01, 02, 03...)`
4. `🔗 Сделать все ссылки программы рабочими (привязать к конспектам)`

### Через меню документа (`...` в правом верхнем углу)
1. `📖 Конспект прочитан — запустить повторение (1-3-7-21-30)`
2. `⏸️ Приостановить повторение конспекта`
3. `🔢 Выровнять нумерацию конспектов (01, 02, 03...)`
4. `🔗 Привязать ссылки программы к конспектам`

---

## Назначение планировщика на документ или папку

1. Откройте нужный документ или папку в RemNote.
2. В правом верхнем углу нажмите **`···`** → **Flashcard Settings** (или найдите команду `Document Flashcard Settings`).
3. В поле **Scheduler** выберите: `Планировщик повторений 1-3-7-21-30`.

## Установка и локальная сборка

### Сборка плагина
```bash
npm install
npm run build
```
После сборки в корне проекта формируется готовый архив `PluginZip.zip`.

### Локальная разработка
```bash
npm run dev
```
Dev-сервер запускается на `http://localhost:8080/`.
