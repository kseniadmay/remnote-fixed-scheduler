# REMNOTE FIXED SCHEDULER

Плагин интервального повторения для RemNote с фиксированным шагом 1-3-7-21-30 дней и контролем очереди изучения.  
Позволяет активировать карточки тем строго после фактического прочтения конспекта и исключает попадание неизученных материалов в очередь практики.  
Включает интеграцию с языковой моделью Claude для переформулирования и технического уточнения карточек.


### 1. Быстрый старт: как учить конспекты без перегрузки очереди
По умолчанию все новые карточки конспектов находятся в режиме ожидания (на паузе), чтобы темы будущих дней и модулей не засоряли очередь практики.

1. Откройте нужный конспект в веб-версии RemNote.
2. Вверху страницы (под заголовком) нажмите кнопку:  
   `📖 Конспект изучен — поставить на повторение`  
   *(либо используйте команду через `/` или `Ctrl + K`: `Конспект прочитан — поставить на повторение (1-3-7-21-30)`)*.
3. Карточки этого конспекта активируются, и первое повторение будет запланировано ровно на **следующий день (+1 день)**.


### 2. Сетка интервалов
Плагин заменяет стандартный адаптивный алгоритм RemNote на предсказуемый фиксированный график:

- **Старт**: +1 день после изучения конспекта
- **1-е повторение**: +3 дня
- **2-е повторение**: +7 дней
- **3-е повторение**: +21 день
- **4-е повторение**: +30 дней
- **Долгосрочный цикл**: 60 → 90 → 180 → 360 дней (с последующим удвоением)

## Возможности

### Основные функции

- **Фиксированный график повторений**: строгая сетка 1-3-7-21-30 без плавающих коэффициентов легкости карточки.  
  _Реализация:_ `plugin.scheduler.registerCustomScheduler` + callback `SpecialPluginCallback.SRSScheduleCard`

- **Контроль очереди изучения (Zero Pollution)**: карточки не прочитанных тем не попадают в практику раньше времени.  
  _Реализация:_ статус паузы карточек по умолчанию + каскадное снятие паузы через `BuiltInPowerupCodes.DisableCards`

- **Интерактивная панель конспекта (`NoteSchedulerBar`)**: визуальный статус темы и переключение режима повторения прямо в документе.  
  _Реализация:_ React-виджет в расположении `WidgetLocation.DocumentBelowTitle`

- **Улучшение формулировок через нейросеть**: автоматическая редактура карточек «вопрос-ответ» для повышения технической точности и лаконичности формулировок.  
  _Реализация:_ батч-запросы к нейросетевой модели Claude через Anthropic REST API


### Доступные названия в интерфейсе RemNote

В настройках колод и документов алгоритм доступен под следующими именами:
- `Планировщик повторений 1-3-7-21-30` (основное)
- `Расписание повторений 1-3-7-21-30` (синоним)
- `Fixed 1-3-7-21-30`


## Команды и меню

### Команды (через `/` или `Ctrl + K`)

- `Конспект прочитан — поставить на повторение (1-3-7-21-30)` — активирует карточки текущего конспекта на завтра
- `Приостановить повторение конспекта` — временно исключает карточки конспекта из очереди повторений
- `Обновить описания карточек в этой папке (Claude)` — запускает нейросетевую обработку формулировок в текущей папке

### Меню документа (`...`)

- `📖 Конспект прочитан — запустить повторение (1-3-7-21-30)`
- `⏸️ Приостановить повторение конспекта`


## Подключение нейросети Claude (опционально)

Функция переформулирования карточек работает через языковую модель Claude:

1. В RemNote перейдите в **Settings** → **Plugins** → **Планировщик повторений 1-3-7-21-30**.
2. В поле `Anthropic API key` укажите ваш ключ (`sk-ant-...`).
3. В поле `Модель Claude` укажите желаемую модель (по умолчанию: `claude-sonnet-5`).

> [!NOTE]
> Доступ к API нейросети тарифицируется компанией Anthropic по количеству токенов через личный кабинет на [console.anthropic.com](https://console.anthropic.com/).  
> Для работы самого планировщика повторений подключение нейросети **не требуется**: интервальный алгоритм полностью автономен, бесплатен и работает локально.


## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/kseniadmay/remnote-fixed-scheduler.git
cd remnote-fixed-scheduler
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Сборка плагина

```bash
npm run build
```
После сборки в корне проекта формируется архив `PluginZip.zip`.

### 4. Установка в RemNote

1. В веб-версии RemNote откройте **Settings** → **Plugins**.
2. Выберите **Install from Zip** (или загрузите `PluginZip.zip` в секции Developer Plugins).
3. Плагин активирован и готов к работе.

Для режима активной разработки:
```bash
npm run dev
```
Сервер запустится локально на `http://localhost:8080/`.


## Назначение планировщика на папку

1. Откройте целевую папку или документ в RemNote.
2. В правом верхнем углу нажмите **`···`** → **Flashcard Settings** (или введите в поиске `Document Flashcard Settings`).
3. В поле **Scheduler** выберите: `Планировщик повторений 1-3-7-21-30`.
