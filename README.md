# Планировщик повторений 1-3-7-21-30 для RemNote

Плагин для RemNote, реализующий строгий интервальный график повторения карточек и умное обновление описаний карточек через искусственный интеллект (Claude AI).

---

## 🎯 Основные возможности

### 1. Планировщик повторений (или «Расписание повторений 1-3-7-21-30»)
* **Полностью бесплатен и автономен** (не требует подключения внешних сервисов и ключей).
* Карточки двигаются строго по фиксированной сетке интервалов, независимо от оценки сложности:
  - 1-е повторение: **+1 день**
  - 2-е повторение: **+3 дня**
  - 3-е повторение: **+7 дней**
  - 4-е повторение: **+21 день**
  - 5-е повторение: **+30 дней**
  - Последующие повторения: **60, 90, 180, 360 дней** (с удвоением интервалов).
* В интерфейсе RemNote в выпадающем списке выбора шедулеров доступен под именами:
  - **`Планировщик повторений 1-3-7-21-30`** (основное название)
  - **`Расписание повторений 1-3-7-21-30`** (дополнительный синоним)

### 2. Обновление описаний карточек через ИИ (Claude)
* Команда в палитре RemNote (`Ctrl + /`): **`Обновить описания карточек в этой папке (Claude)`**.
* Находит все карточки внутри выбранной папки и улучшает формулировки «вопрос-ответ», делая их точными, лаконичными и понятными.

> [!IMPORTANT]
> **Важно об использовании ИИ (Claude API):**
> Для работы функции обновления описаний карточек через ИИ необходимо указать собственный **Anthropic API key** (`sk-ant-...`) в настройках плагина.
> 
> * **API у Anthropic является платным** и тарифицируется по количеству токенов через личный кабинет на [console.anthropic.com](https://console.anthropic.com/).
> * Если вам нужен **только планировщик повторений**, вводить API-ключ **НЕ требуется** — интервальные повторения работают локально, бесплатно и не зависят от внешних сервисов.

## 🚀 Установка и подключение к RemNote

### Вариант 1. Через Developer Plugins (локальный dev-сервер)
1. Установите зависимости и запустите dev-сервер:
   ```bash
   npm install
   npm run dev
   ```
2. В веб-версии RemNote перейдите в **Settings** (`Ctrl + ,`) → **Plugins** → блок **Developer Plugins**.
3. Нажмите **«Add Developer Plugin»** (или «Разрабатывать с localhost»), укажите адрес:
   ```
   http://localhost:8080/
   ```
4. Нажмите синюю кнопку **«Разрабатывать»**.

### Вариант 2. Установка из готового архива
1. Соберите zip-архив:
   ```bash
   npm run build
   ```
2. В RemNote: **Settings** → **Plugins** → **Install from Zip** → выберите файл `PluginZip.zip`.

## 📌 Как назначить планировщик на нужную папку

1. Откройте в RemNote папку с конспектами/карточками (например, «Теория»).
2. В правом верхнем углу нажмите меню **`···`** (три точки) → **Flashcard Settings** *(либо нажмите `Ctrl + /` и введите `Document Flashcard Settings`)*.
3. В строке **Scheduler** выберите:
   **`Планировщик повторений 1-3-7-21-30`** *(или «Расписание повторений 1-3-7-21-30»)*.
4. Все карточки внутри этой папки теперь следуют вашему интервальному режиму!
